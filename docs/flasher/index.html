ButtonBridge installer

Puts the bridge firmware on an ESP32-P4 or ESP32-S3 board, straight from your browser.

  1. Use Chrome or Edge on a computer (phones and Safari can't do this).
  2. Plug the board into the computer with a USB cable that carries data: the USB-C port on the Waveshare ESP32-P4 board, or the port marked USB on an ESP32-S3.
  3. Press Install, pick the board's serial port, and confirm. It takes a minute or two.
This browser can't talk to USB devices. Open this page in Chrome or Edge on a computer. This page needs to be opened over https.

The right file for your chip, including older ESP32-P4 revisions, is picked automatically.

Board not found? Hold its BOOT button while you plug it in, then press Install again.

Using Wi-Fi? (ESP32-S3, or an ESP32-P4 without a network cable) After installing, keep the board plugged in and run firmware/bridge/tools/set_wifi.py: it asks for the network name and password. See docs/INSTALL.md.

Next: plug in the Stream Deck (and the network cable, unless it's on Wi-Fi), then add the ButtonBridge app to Home Assistant. The full guide is in the repository's docs/INSTALL.md.
